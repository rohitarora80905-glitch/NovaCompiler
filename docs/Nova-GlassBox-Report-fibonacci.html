What this program is

Nova is a complete compiler for an original programming language, written in pure Python. It takes a .nova source file all the way to bytecode, verifies that bytecode is safe, and runs it. Every intermediate form the compiler builds is kept and shown, which is why it is called a glass box: nothing inside is hidden.

Module 2 — Syntax analysis

The same grammar drives four parsers so they can be compared honestly: a hand-written recursive-descent parser (which builds the AST the rest of the compiler uses) and the SLR, CLR and LALR table-driven parsers (which independently re-parse the same token stream). If the two disagreed, one of them would be wrong.

The Nova grammar

  0. program -> decls
  1. decls -> decls decl
  2. decls -> ε
  3. decl -> func
  4. decl -> stmt

Module 4 — Intermediate code

Three-address code: at most one operator per instruction, so every instruction maps to roughly one machine instruction later. Boolean expressions are compiled as jumping code, so a and b never evaluates b when a is false. The jump targets are unknown when the jump is emitted, so they are left blank and backpatched once the destination is reached.

Module 6 — Code generation

Registers are scarce, so the generator computes next-use information: for every value, how far away is the next instruction that reads it. When all registers are full, the one whose value is needed furthest in the future is spilled to the activation record. This is Belady's rule applied to registers, and it is what the descriptor tables below record.
