What this program is

Nova is a complete compiler for an original programming language, written in pure Python. It takes a .nova source file all the way to bytecode, verifies that bytecode is safe, and runs it. Every intermediate form the compiler builds is kept and shown, which is why it is called a glass box: nothing inside is hidden.

# Written badly on purpose, so the optimiser has work to do.
#
#   * width * height does not change inside the loop -> hoisted out (LICM)
#   * it is then computed a second time              -> common sub-expression
#   * i * 8 grows by a fixed step each iteration     -> strength reduced
#   * 99 * 3 is known at compile time                -> constant folded
#   * 'unused' is never read                         -> dead code eliminated
#
# 'measure' hides its result from the optimiser, so width and height really are
# unknown at compile time - otherwise constant folding would finish the job
# before loop-invariant code motion ever got a turn.

func measure(x)
    return x;
end

let n = 5;
let width = measure(4);
let height = measure(6);
let i = 0;
let acc = 0;
let unused = 99 * 3;

while i < n do
    let area = width * height;
    let scaled = i * 8;
    acc = acc + area + scaled;
    let dup = width * height;
    acc = acc + dup;
    i = i + 1;
end
print acc;

Module 1 — Lexical analysis

Each token is written as an extended regular expression. Those expressions are combined into one syntax tree, and nullable, firstpos, lastpos and followpos are computed on it — the direct method, which builds the DFA without ever constructing an NFA. The DFA is then minimised and used to scan the input with the longest-match rule. Python's re module is never imported.

Module 4 — Intermediate code

Three-address code: at most one operator per instruction, so every instruction maps to roughly one machine instruction later. Boolean expressions are compiled as jumping code, so a and b never evaluates b when a is false. The jump targets are unknown when the jump is emitted, so they are left blank and backpatched once the destination is reached.
